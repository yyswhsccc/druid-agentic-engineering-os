How to read the evidence

Finding

Risk appears at boundaries

Druid looks where code crosses trust, value, state, or operations boundaries: payout status, bridge state, UTXO ownership, CORS, admin gates, and env defaults.

Proof

A patch needs a reason

Each useful PR should explain what can go wrong, why the existing behavior matters, and what regression test prevents the mistake from returning.

Maintenance

The loop continues after opening

CI, maintainer comments, superseding work, merge/close outcomes, and stale PR cost all feed the next decision.
